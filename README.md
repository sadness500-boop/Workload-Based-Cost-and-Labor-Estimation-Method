# Workload-Based Cost and Labor Estimation Method

**업무량 기반 비용 및 인력 산정 방식** · 에스텍 그룹 · v1.7

용역계약(보안·미화·주차·시설·기타)을 "인당 견적"이 아니라 **업무량**으로 산정하는 프로그램입니다.

1. 사업장 유형 선택 — 공장 · 빌딩 · 병원 · 유통 · 대학교 · 연수원 · 발전소 · 아파트 · 기타
2. 직종 선택 — 보안 · 미화 · 주차 · 시설 · 기타
3. 업무를 대 · 중 · 소 · 세부로 분류하고 업무별 기본시간 입력
4. 업무량 → 월 업무시간 → 필요 인원(미화는 남 · 여 구분) → 인건비 · 견적
5. 견적 금액을 분류된 업무별 비용으로 배분 (합계는 견적과 원 단위까지 일치)

### 산정 방식 두 가지

| 방식 | 입력 | 결과 |
|---|---|---|
| **A. 업무량 기반 비용 및 인력 산정** | 업무 분류표의 업무량 · 사업장 기본규모 | 필요 인원 → 인력 견적 → 업무별 비용 |
| **B. 견적서 기반 업무별 비용 산정** | 에스텍 견적서 엑셀 불러오기(PC·구글 드라이브·네이버 MYBOX) 또는 인원·금액 입력, 포함 업무 체크(대·중·소·세부) | 견적 인원이 할 수 있는 업무량 · 부족 인력 · 업무별 비용 배분 |

**엑셀 견적서**

- A 방식: 업무량으로 산정한 인원을 에스텍 견적서 양식(표지 · 견적서 · 산출내역서 · 부대비용)으로 내보내고, ‘업무별 비용 배분’ 시트에 견적 월 합계를 업무마다 나눠 넣습니다.
- B 방식: 받은 견적서를 불러와 체크한 업무량과 견적 인원의 근무시간을 비교합니다. 부족하면 “부족 인력 +○명 반영 견적서”를, 충분하면 “업무별 비용 포함 견적서”를 내보냅니다.
- 두 방식은 같은 양식을 쓰므로 A에서 만든 견적서를 B에서 다시 불러올 수 있고, 이때 업무량도 함께 불러와 A와 B의 모든 숫자가 원 단위까지 같습니다.
- 견적 연도: **당해년 / 익년** 중 선택. 최저임금·4대보험 요율은 에스텍시스템 견적 기준(2026: 10,320원 · 국민연금 4.75% · 고용 1.75%, 2027: 10,700원 · 국민연금 5.0% · 고용 1.85%, 건강 3.595% · 장기요양 13.14% · 산재 0.86%).
- 추가 시트: **업무별 비용 배분**(업무별 직접·간접노무비·경비·일반관리비·이윤, 월·연 배분액, 검증 행) · **업무량 산출내역**(Workload 양식 — 평일·주말·공휴일 × 주간·야간 시간과 금액).
- 시트 순서: A = 표지 · 견적서 · 업무별 비용 배분 · 업무량 산출내역 · 산출내역서 · 부대비용 / B = 원본 순서 + 맨 뒤에 두 시트 추가.
- 예시 파일: `samples/` 폴더.
